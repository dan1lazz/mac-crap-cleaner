# Changelog

Все заметные изменения проекта. Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [2.2.2] — 2026-11-17

### Ускорено
- **«Анализ диска» больше не «зависает» на больших домашних каталогах.**
  Подкаталоги измеряются параллельно (пул потоков, один проход `tree_stats`
  на каталог): раньше обход был последовательным и экран надолго замирал
  на первом большом каталоге (`Library`, `Pictures`…), особенно на холодном
  дисковом кэше.

### Добавлено
- GitHub Actions: релиз по пушу тега — прогон всех 346 тестов, сборка
  `.app` и бандла, публикация с заметками из CHANGELOG.md.

## [2.2.1] — 2026-11-17

### Ускорено
- **Поиск остатков программ (`orphans`) — до 10× быстрее.** Сначала выполняется
  дешёвая классификация по имени, и только выжившие кандидаты измеряются:
  данные установленных программ и системы больше не обходятся вовсе.
  Измерение идёт параллельно в пуле потоков.
- **Один проход по дереву вместо двух.** Размер, число файлов и mtime
  собираются одним обходом (`tree_stats`) в `orphans`, глубоком скане и
  измерении целей очистки — раньше `dir_size()` и `newest_mtime()` обходили
  каждый каталог дважды.
- **Реестр программ собирается быстрее:** чтение `Info.plist` у найденных
  Spotlight'ом приложений параллелится.

### Исправлено
- `build_app.py` сам собирает недостающий бандл (`build_bundle.py` вызывается
  автоматически) — сборка `.app` снова одной командой.
- Версия в `.app` (`Info.plist`) берётся из `mactweaker/__init__.py`
  (было рассинхронизировано: 2.1.0 против 2.2.0).
- README: актуальные пути (`mac_cc`), версия, размер бандла.

### Оформление
- README: переключатель языков EN/RU в шапке, бейджи (релиз, macOS, Python,
  ноль зависимостей, MIT), кнопка скачивания `.app` из релизов.
- Релизы оформляются по этому changelog: что ускорено, что исправлено,
  что добавлено.

## [2.2.0] — 2026-11

### Добавлено
- Совместимость с macOS 13–27 (Ventura → Golden Gate): профиль `OSFeatures`,
  гейтинг твиков по версии ОС, проверка Full Disk Access, APFS-снапшоты.
- Современные пожиратели места (Ollama, LM Studio, OrbStack, Docker, HuggingFace)
  — под отдельным подтверждением, никогда не отмечены по умолчанию.
- Обёртка `.app` для запуска двойным кликом.

### Ускорено
- Параллельный обход дерева (`ThreadPoolExecutor`) в сканерах.
- `tree_stats()` — размер/файлы/mtime за один проход в сканере кэшей.
